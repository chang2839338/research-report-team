# Research Report Team

Local web app for running a quality-first report workflow through Codex.

This project does not call the OpenAI API directly. The server keeps using
`codex exec` role by role:

`Manager -> Researcher -> Evidence Auditor -> Analyst -> Writer -> Reviewer -> Revision Writer when needed -> Final Verifier -> Publisher`

## Run

```powershell
python .\scripts\research_team_server.py --port 8765
```

Open `http://127.0.0.1:8765` in a browser.

For higher quality research, pass the Codex model through the existing CLI option:

```powershell
python .\scripts\research_team_server.py --port 8765 --codex-model gpt-5
```

If `--codex-model` is omitted, Codex uses its configured default model.

## Quality-First Artifacts

New runs use one shared artifact contract across the server, CLI, and UI.

- `artifacts/00_task_brief.md`: shared task brief.
- `artifacts/01_research.md`: research memo.
- `artifacts/01_sources.md`: source ledger.
- `artifacts/01_claims.md`: claim evidence table.
- `artifacts/01_gaps.md`: research gaps and risks.
- `artifacts/01_numeric_assumptions.md`: numeric assumptions ledger.
- `artifacts/02_evidence_audit.md`: audit of source and numeric traceability.
- `artifacts/03_analysis.md`: decision criteria, scenarios, and recommendation logic.
- `artifacts/04_draft.md`: writer draft.
- `artifacts/05_review.md`: reviewer score and full claim audit.
- `artifacts/06_revision.md`: targeted revision when review requires it.
- `artifacts/07_final_verification.md`: final quality gate.
- `artifacts/08_final.md`: final Markdown report.
- `artifacts/08_final.docx`: local Word copy generated by the server.
- `artifacts/08_final_manifest.json`: publication metadata.

The Researcher returns multiple artifacts in one Codex response using exact
artifact markers. If a required marker is missing, duplicated, out of order, or
empty, the run fails and writes details to `error.log`.

## Workflow Notes

1. Enter a report title and brief.
2. Click `작업 실행`.
3. The server runs Codex role by role without direct API calls.
4. Prompts are saved in `prompts/`.
5. Agent replies are saved in `artifacts/`.
6. Token usage and role history are saved in `status.json`.
7. Codex JSON events are appended to `events.ndjson`.
8. Final state is `completed` only when Markdown, DOCX, and final manifest exist.

Existing historical runs are preserved as-is; new runs use the quality-first
contract and UTF-8 Korean labels.
